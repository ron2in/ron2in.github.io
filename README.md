# ron2in.github.io

Главный веб-портал и единая точка входа для проектов и интерактивных инструментов **ron2in**.

**Сайт:** https://ron2in.github.io/

## Возможности портала
- **Автоматическая синхронизация с GitHub** — публичные репозитории пользователя `ron2in` подгружаются через GitHub API.
- **Фильтрация и поиск** — быстрый отбор по категориям (**Все**, **С сайтом (GitHub Pages)**, **Репозитории**) и поиск по названию, описанию и языку.
- **Закреплённые проекты** — [Harmony & Chord Lab](https://ron2in.github.io/harmony-lab/) всегда отображается первым в списке.
- **Адаптивный интерфейс** — корректно работает на ПК и смартфонах в тёмной теме.

## Структура
- `index.html` — статическая страница портала (HTML + CSS + JS без сборщиков и внешних зависимостей).
