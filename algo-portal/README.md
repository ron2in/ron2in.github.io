# AlgoPortal

Интерактивный веб-портал для изучения алгоритмов и структур данных на базе материалов **e-maxx.ru / cp-algorithms**. Работает прямо в браузере на ПК и смартфонах без серверной части и сборщиков, с поддержкой офлайн-режима (**PWA**) и синхронизацией с **Codeforces**.

**Сайт:** https://ron2in.github.io/Algo-portal/  
**Главный портал:** https://ron2in.github.io/

## Основные модули

1. **Интерактивные визуализаторы (22 темы)**
   - **Поиск и массивы:** Бинарный поиск (`lower_bound`), Метод двух указателей, Сортировки и префиксные суммы.
   - **Графы:** BFS, Алгоритм Дейкстры, DFS (3 цвета, циклы, топологическая сортировка), Алгоритм Крускала (MST), Поиск мостов и точек сочленения (`tin/fup`), Компоненты сильной связности (Косарайю), Задача о назначениях (Венгерский алгоритм).
   - **Деревья и структуры данных:** Дерево отрезков, Дерево Фенвика (BIT), DSU (сжатие путей и ранги), LCA (двоичные подъёмы).
   - **ДП и строки:** 0-1 Рюкзак, Задача коммивояжёра (TSP по маскам), LCS и Расстояние Левенштейна, Префикс-функция (КМП) и Z-функция.
   - **Теория чисел:** Решето Эратосфена, Бинарное возведение в степень, Расширенный алгоритм Евклида, Китайская теорема об остатках (КТО).
2. **Профессиональный дебаггер (Dry-Run)**
   - Синхронная подсветка выполняемой строки кода, таблица текущих переменных и лог изменений (**Watchlist Log**).
   - Точки останова (**Breakpoints**, `F9`), условная перемотка (**Step Until**), горячие клавиши плеера и режим **«Угадай следующий шаг»**.
   - Режим презентации / проектора (`F` или `Alt+P`) и вставка тестов напрямую в формате Codeforces.
3. **Практика и тестирование в браузере**
   - Шаблоны на **C++** и **Python**, тренажёр **«Допиши 1–3 строки»**, мини-тесты на асимптотику.
   - **Песочница Python (Pyodide)** — ленивый запуск пользовательского кода против скрытых юнит-тестов прямо в браузере.
   - **Интеграция с Codeforces API** — подборка реальных задач по тегу и рейтингу, синхронизация профиля (`✓ AC`, скрытие решённых, фильтр под свой рейтинг).
4. **Инструменты для контестов**
   - **Анализатор ограничений (`N → O`)** для C++ и Python/PyPy.
   - **Генератор тестов** (массивы, перестановки, строки, деревья через код Прюфера, графы, DAG).
   - **Справочник STL (C++) vs Python** (с защитой `splitmix64` от анти-хеш тестов).
   - **Тренажёр побитовых операций** (16 бит, сдвиги, маски, перебор подмасок).
   - **Блиц-тренировка** и **Охота на баги** (классические ловушки + процедурный генератор мутаций).
   - **Сборщик Тимбука (ICPC Reference)** с двухколоночной печатью в PDF, таймер контеста и бэкап прогресса/заметок в JSON.

## Структура проекта

```text
algo-portal/
├── index.html              # Оболочка, навигация, таймер контеста и роутинг
├── manifest.json           # PWA-манифест
├── sw.js                   # Service Worker (Cache First для статики, Network First для API)
├── README.md               # Документация проекта
├── css/
│   └── style.css           # Тёмно-графитовая тема, адаптив и @media print для Тимбука
├── data/
│   ├── topicsIndex.js      # Лёгкий индекс тем и динамический загрузчик модулей
│   └── topics/             # Модули тем по категориям (arrays, graphs, trees, dp, strings, math)
└── js/
    ├── app.js              # Роутинг, прогресс, заметки, профиль CF и сборщик Тимбука
    ├── player.js           # Пошаговый плеер с breakpoints, Step Until и горячими клавишами
    ├── cfApi.js            # Интеграция с Codeforces API (кэш 30 мин, rate-limit)
    ├── pyodideRunner.js    # Ленивый раннер Python в браузере
    ├── tools.js            # Генератор тестов, справочник STL, битовый тренажёр, блиц
    ├── advancedTools.js    # Охота на баги и мастер выбора алгоритма
    └── engines/            # Визуализаторы: arrayEngine, graphEngine, gridEngine, treeEngine, mathEngine, stringEngine
```
